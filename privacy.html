Privacy policy

Effective September 9, 2026

Owner-only application. This application serves the channel operator and expressly authorized operators. It does not accept public user registrations.

Scripture Story Atlas is a private video production application operated by the owner of the Scripture Story Atlas YouTube channel. It supports illustrated, English-language biblical storytelling for adults. This policy covers the application, its Google account connection, and this informational site.

For privacy questions, access requests, corrections, or deletion requests, contact youtubedarkchannel@gmail.com.

1. Information the application accesses

The application uses YouTube API Services. With the channel owner’s consent, it requests these Google permissions:

  • youtube.readonly: the connected channel identifier and video details needed for upload validation, including titles, descriptions, channel identifiers, visibility, audience and language settings, processing status, duration, and available file or video stream details.
  • yt-analytics.readonly: daily channel or video performance reports. The current worker collects reports for published videos, including views, engaged views, estimated minutes watched, average view duration and percentage, subscribers gained or lost, likes, comments, and shares. These are report totals, not individual viewer profiles or comment text.

Google handles account sign-in. The application receives OAuth authorization tokens and stores the refresh token with the owner’s private connection configuration so it can renew access. It does not ask for or store the owner’s Google password. These permissions do not include uploads, video editing or deletion, advertising revenue, Gmail, or Google Drive.

The production workflow also stores story sources, scripts, illustrations, narration, captions, editorial feedback, approvals, video and publishing identifiers, provider receipts, operating events, and cost records. If you email support, the operator receives your email address and the information you choose to send.

2. How information is used and shared

YouTube data supports channel identification, private-upload checks, publication confirmation, owner-visible performance reports, and editorial guidance for future videos. Reports and private upload details are available through the private production desk to the owner and any people the owner expressly authorizes.

Google user data is used for the features described here, subject to the Google API Services User Data Policy and its Limited Use requirements. The application does not sell Google user data, use it for personalized advertising or credit decisions, or train its own AI models on it.

The production services have distinct roles:

  • Google / YouTube processes authorization and API requests. Google’s handling of data is described in the Google Privacy Policy.
  • Google Gemini receives story briefs, source passages, scripts, editorial feedback, and artwork for generation or review. When the editorial learning feature is active, the brief can include a recommendation referencing an episode title selected using YouTube performance data. Raw analytics report rows and OAuth tokens are not included in those generation prompts.
  • ElevenLabs receives narration text and voice or pronunciation settings to create speech and timing information.
  • Publer and TikTok receive finished media and publishing instructions, including titles, descriptions, account identifiers, visibility, and schedules. Their account authorizations are separate from this application’s read-only Google connection.
  • Telegram, when configured, delivers private owner alerts. These can contain episode titles or identifiers, review and publication status, and operating errors. They are sent to the owner’s configured private chat.
  • Hetzner hosts the private production application. Backblaze B2, when connected, stores encrypted backups on the operator’s behalf. The owner also retains an encrypted recovery copy on a private computer. Backup copies can include the same application records described here.

Each provider operates under its own terms and privacy practices. Processing may take place outside your country. Information may also need to be disclosed where required by applicable law or to address a security incident.

3. Storage, security, and retention

The application stores its working records in the operator’s database and media files. OAuth refresh credentials are kept in private runtime configuration. The application does not itself encrypt its local database or credential files. Access depends on the operator’s device or server protections and private-dashboard access controls. Provider API requests use HTTPS.

Local database snapshots can include YouTube report rows and upload validation records. If off-host backups are enabled, those records can also be included in encrypted backup snapshots.

Google API data is retained only for the authorized channel-management purposes described here. The operator must verify continuing authorization and refresh or remove retained API data as required by YouTube’s policies; archiving a generated video is a separate operation and does not delete its API records. Deletion requests are handled manually by the operator within seven days, including removal from active records and recovery copies. If a backup is restored, the operator must apply recorded deletion requests before restarting production.

4. Your control and deletion requests

You can revoke this application’s Google access at any time through Google Account permissions. Select Scripture Story Atlas and remove its access. This stops future authorized API access; it does not by itself erase copies already held by the application.

To request deletion of the application’s stored Google data, email youtubedarkchannel@gmail.com with the channel identifier and a description of your request. Do not include passwords, API keys, or tokens. The owner handles requests manually and may need to verify your authority over the channel.

Deleting this application’s copies does not delete data or videos on YouTube. Manage those in YouTube. Removing this application’s Google access also does not disconnect Publer or cancel posts already scheduled there; manage those separately in Publer.

5. Website, cookies, and children

This informational site is hosted by GitHub Pages. It has no registration form, embedded video, advertising, analytics script, external font, or tracking cookie added by the operator. GitHub may process technical connection information, including IP addresses and browser request details, under its privacy statement. The operator does not receive GitHub’s raw visitor access logs.

The separate private production desk uses a session cookie to keep the operator signed in. It is not an advertising cookie. Opening external links takes you to services governed by their own policies.

The application is intended for the adult channel owner and is not offered to children. It does not seek personal information from children. Contact the operator if you believe a child has submitted personal information.

6. Changes and contact

The operator will update this policy when data practices change and seek renewed consent where required before using Google data for a newly disclosed purpose. Questions or complaints can be sent to youtubedarkchannel@gmail.com.
